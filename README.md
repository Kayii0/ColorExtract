# 🎨 ColorExtract

**ColorExtract** is a web-based color palette generator built with Python and Streamlit. It uses Machine Learning (K-Means clustering) to extract dominant colors from any uploaded image and displays them in a clean, interactive UI with their corresponding HEX codes.

👉 **Try it live here:** [colorextract.streamlit.app](https://colorextract.streamlit.app)

---

## ✨ Features
* **Drag-and-Drop Uploader:** Easily upload any JPG, JPEG, or PNG image.
* **K-Means Clustering:** Uses `scikit-learn` and `numpy` to accurately find the dominant color palette.
* **Customizable Palette Size:** Adjust the number of colors dynamically using a slider.
* **Instant HEX Codes:** Clear visual color swatches with copy-friendly HEX values.

---

## 🚀 Tech Stack
* **Python**
* **Streamlit** (Web Interface)
* **Scikit-learn** (K-Means Algorithm)
* **Pillow (PIL)** & **NumPy** (Image Processing)
